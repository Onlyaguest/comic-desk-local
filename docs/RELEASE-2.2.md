# 融合版 2.2 分发更新

2026-11-19。保留通用桌面配色与离线优先的启动方式。

本次加入便签墙关注、物件摆放记忆、四路事项/会话卡、独立时效提示、纸卡协作背面，以及完整已登记图片的分页、缩略图状态和本地 PhotoSwipe 缩放。

发布包只含源码、第三方组件许可证和虚构样例；个性化空间桥、账号、聊天、回写记录、数据库、私人图片、主页配置和自启配置均不在包内。个人数据只在显式启用后读取，协作信息只读本项目自行登记的配置。

新版与旧桌面共享账本；首次样例升级只补一条 Claude 会话，不重置勾选或便签。升级前备份自己的 data/；只替换源码。回退可重新取得上一版源码并保留 data/，不要覆盖已有账本。新增的融合偏好和缓存可留在本机，旧版本不依赖它们。

发布验证命令：

```sh
bash verify.sh
python3 tools/smoke_release.py
python3 tools/audit_release.py --history
```

自检和审计均使用包含未暂存新增文件的候选源码清单；无须为了测试先提交。审计可额外接收仓库外本机隐私标识清单，并导出逐文件 SHA-256。空 HOME 黑盒自检覆盖启动、四端卡、证据、图片、作品预览、账本重开/重启保留、0外部CLI隔离及同源边界。

可选浏览器回归需环境自行提供 Playwright 与 Chrome；启动样例服务后使用：

```sh
DESK_QA_URL=http://127.0.0.1:7777 node tools/browser_smoke.cjs
```

可用 DESK_CHROME 指定浏览器路径，DESK_QA_DIR 指定仓库外截图目录。脚本禁止对非回环地址的网络请求，并验证便签墙、来源/搜索、协作背面、图像缩放及手机布局。
