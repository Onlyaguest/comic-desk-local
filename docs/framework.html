LOCAL DESK · FRAMEWORK

桌面即索引
Desk as Index

一张桌子不是数据库，是一张索引。数据在 data/，入口在 links.json，时间在 schedule.json；桌面只负责把它们画出来。

▣ 数据是本地纯文本 ↗ 一物一指针 ◷ 时钟交给本地 agent

读法：左边进数据，中间是真相，右边是桌面。实线是“编译”，虚线是“回写”。关掉桌面，data/ 还在。

物 · Objects你每天真的会点、会碰的东西。不常用的不上桌。
指针 · Pointers每个物件都指向一个真实位置：文件、网页、App、会话。
时钟 · Clock桌面不装 cron；只写“该想什么”，执行交给 agent。

三条规则，撑住整张图

纯文本优先JSON / JSONL / Markdown：平台不在了，文件还在。
一物一指针点下去不知道去哪的物件，删掉。
只追加便签和待办是动作日志，当前状态靠回放。
时钟外置定时是 prompt 清单，判断和执行归 agent。
